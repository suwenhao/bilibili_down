# 下载校验与安全软件提示说明

BiliDown 包含下载引擎、音视频处理组件和本地文件操作能力。部分系统或安全软件可能会因为“未签名、下载量较少、包含 aria2/FFmpeg”等原因弹出风险提示。风险提示不一定代表文件被篡改，但你应该先确认来源和文件完整性，再决定是否继续使用。

## 推荐下载来源

请优先从以下位置下载：

- 项目 GitHub Releases。
- README 或发布说明中明确列出的 HTTPS 下载地址。

不建议从网盘转载、第三方下载站、聊天群转发压缩包或改名文件安装。如果文件名、大小或 SHA-256 与发布页不一致，请删除后重新下载。

## 校验 SHA-256

发布包通常会同时提供 `SHA256SUMS.txt`。你可以用它确认下载文件没有在传输或镜像过程中被改动。

Windows PowerShell 示例：

```powershell
Get-FileHash .\BiliDown-windows-x64.zip -Algorithm SHA256
```

macOS / Linux 终端示例：

```bash
sha256sum ./BiliDown-linux-x64.tar.gz
```

把命令输出的哈希值与 `SHA256SUMS.txt` 中对应文件的值逐字对比。完全一致，才说明文件完整。

## 遇到安全软件提示怎么办

建议按下面顺序处理：

1. 确认文件来自官方发布页或 README 中列出的下载地址。
2. 校验 SHA-256，确认文件没有被改动。
3. 查看发布页中的第三方组件和许可证说明，确认随包组件来源。
4. 如果仍不放心，请暂时不要运行该文件。
5. 如果你确认是误报，可以把官方发布链接和 SHA-256 提交给安全软件厂商复核。

不建议直接关闭安全软件或绕过系统保护。更稳妥的做法是先校验来源和哈希。

## BiliDown 会做什么

- 解析你输入或确认解析的 B 站链接。
- 在你选择的目录保存下载文件。
- 使用本地下载引擎和 FFmpeg 组件处理媒体文件。
- 在你开启后监听剪贴板中的 B 站链接。
- 在你主动导出时生成脱敏诊断日志。

## BiliDown 不会做什么

- 不上传你的下载历史、本地文件或诊断日志给 BiliDown 开发者。
- 不静默下载剪贴板中的内容。
- 不提供 DRM 破解、会员权限提升或地区限制绕过。
- 不要求你关闭安全软件。

更多数据处理说明见 [隐私声明](privacy.md)。
