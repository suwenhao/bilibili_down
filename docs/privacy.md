# BiliDown 隐私声明

更新日期：2026-07-31

## 数据处理原则

BiliDown 不运营账号服务器、统计服务或广告服务，不会把下载历史、诊断日志或本地文件上传给 BiliDown 开发者。应用仅在实现你明确操作的功能时，与哔哩哔哩及其内容分发域名通信。

## 本地保存的数据

- B 站 Cookie 与 Refresh Token 保存在操作系统安全存储中。
- 下载任务、进度、输出路径和文件记录保存在本地 SQLite 数据库中。
- 主题、下载目录、画质、音质、编码、命名规则等偏好保存在本地设置中。
- 封面缓存、下载临时文件和崩溃标记保存在应用数据目录或你选择的下载目录中。
- 诊断日志默认只保留在应用运行时内存中；只有你主动选择“导出脱敏日志”时，才会写入你选择的位置。

## 网络请求

解析、登录、会话刷新、字幕、弹幕和媒体下载会向哔哩哔哩相关域名发送必要请求。登录后，请求可能携带 Cookie、Referer 和 User-Agent，以获取当前账号有权访问的资源。

BiliDown 不承诺或绕过会员、版权、地区及风控限制。

## 系统权限

- 通知权限：用于显示下载完成、失败和后台状态。
- Android 前台服务和 WorkManager：用于维持或恢复你发起的下载任务。
- iOS 后台下载能力：用于系统允许范围内的后台传输。
- 文件与目录选择权限：用于保存下载文件和导出日志。
- 剪贴板读取：仅在你开启剪贴板监听后，用于检测 B 站链接；不会上传或保存其他剪贴板内容，也不会静默开始下载。

## 数据删除

- 退出登录会尝试注销远端会话，并清除本机保存的 Cookie 与 Refresh Token。
- 设置页可以清除应用缓存。
- 任务页可以删除任务记录；如果你选择同时删除文件，成品文件也会被删除。
- 卸载应用通常会清除系统管理的应用私有数据；公共下载目录中的文件需要你自行确认删除。

## 反馈问题

反馈问题时，请不要公开 Cookie、账号二维码、下载链接中的敏感参数或私人文件路径。需要排查时，优先使用应用内“导出脱敏日志”生成的文件。
