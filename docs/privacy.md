# BiliDown 隐私声明

更新日期：2026-07-12

## 数据处理原则

BiliDown 不运营账号服务器、统计服务或广告服务，不会把下载历史、诊断日志或本地文件上传给 BiliDown 开发者。应用仅在实现用户明确操作时与哔哩哔哩及其内容分发域名通信。

## 本地保存的数据

- B 站 Cookie 与 Refresh Token 保存在操作系统安全存储（Keychain、Keystore 或系统凭据库）中。
- 下载任务、进度、输出路径和产物索引保存在本地 SQLite 数据库中。
- 主题、下载目录、画质及其他非敏感偏好保存在本地应用设置中。
- 封面缓存、下载临时文件和崩溃标记保存在应用数据目录或用户选择的下载目录中。
- 诊断日志仅保留最近的有界内存记录；只有用户主动选择“导出脱敏日志”时才写入用户选择的文件。

## 网络请求

解析、登录、会话刷新、字幕、弹幕和媒体下载会向哔哩哔哩相关域名发送必要请求。登录请求会携带安全存储中的 Cookie；媒体请求可能携带 Referer、User-Agent 与 Cookie，以获得账号有权访问的资源。BiliDown 不承诺或绕过会员、版权、地区及风控限制。

## 系统权限与后台能力

- 通知权限用于显示下载完成、失败及后台状态。
- Android 前台服务和 WorkManager、iOS 后台能力用于维持或恢复用户发起的下载任务。
- 文件与目录选择权限仅用于用户指定的下载位置和主动导出的日志。
- 剪贴板监听仅在用户开启该设置时检测 B 站链接；不会上传或保存其他剪贴板内容，也不会静默开始下载。

## 数据删除

退出登录会尝试注销远端会话，并始终删除本地 Cookie 与 Refresh Token。设置页可以清除封面缓存；任务页可以删除任务记录，并在用户明确勾选后删除对应成品文件。卸载应用可清除由系统管理的应用私有数据，公共下载目录中的文件需要用户自行确认删除。

## 联系与变更

本项目当前未配置远端反馈或数据控制者联系方式。发布前应在商店元数据和本声明中补充维护者的有效联系渠道。功能或数据处理范围变化时，应同步更新本声明及商店隐私标签。
